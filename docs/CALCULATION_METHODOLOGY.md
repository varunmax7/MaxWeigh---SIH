## 2. Maximum permissible error (Table 6)

MPE is expressed as a multiple of `e`, banded by `m = load / e`:

| Class | ±0.5 e | ±1.0 e | ±1.5 e |
|---|---|---|---|
| I | 0 ≤ m ≤ 50000 | 50000 < m ≤ 200000 | m > 200000 |
| II | 0 ≤ m ≤ 5000 | 5000 < m ≤ 20000 | m > 20000 |
| III | 0 ≤ m ≤ 500 | 500 < m ≤ 2000 | m > 2000 |
| IIII | 0 ≤ m ≤ 50 | 50 < m ≤ 200 | m > 200 |

In-service MPE = **2 × initial MPE** (clause 3.5.2).

## 3. Error of indication (clause 4.5)

**Change-point method** (`d = e`):

```
P  = I + ½e − ΔL
E  = P − L
Ec = E − E0
```

**Direct method** (`d ≤ 0.2 e`, high-resolution/service indication): `P = I`, `E = I − L`.

A row passes when `|Ec| ≤ mpe(L)`, inclusive, compared before any display rounding.

### Worked example — class III, Max 30 kg, e = d = 5 g

Zero reference: L = 50 g, I = 50 g, ΔL = 3.0 g → P = 49.5 g, **E0 = -0.5 g**.

| L (g) | I (g) | ΔL (g) | P (g) | E (g) | Ec (g) | mpe (g) | Verdict |
|---|---|---|---|---|---|---|---|
| 10000 | 10000 | 1.5 | 10001 | 1 | 1.5 | 5 | PASS |
| 30000 | 30005 | 0.5 | 30007 | 7 | 7.5 | 7.5 | PASS |
| 2500 | 2505 | 4.5 | 2503 | 3 | 3.5 | 2.5 | FAIL |

`mpe(L) / 3`.
